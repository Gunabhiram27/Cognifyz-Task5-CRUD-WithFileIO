# Task 5 – CRUD with File Storage 💾

This console-based CRUD application extends Task 3 by adding file I/O to save and load tasks persistently.

## 📌 Features
- Add, update, delete tasks
- Tasks saved to and loaded from `tasks.txt`
- File handling with error checks

## 🛠️ Technologies Used
- Java
- Maven
- IntelliJ IDEA
- File I/O (BufferedReader, PrintWriter)

## 🚀 How to Run
1. Open in IntelliJ
2. Run `TaskManager.java`
3. Tasks are saved in `tasks.txt` in the project root
